# 지도 데이터 필드

`seed`는 32비트 게임 시드, `selectedOptional`은 한 번 추첨하고 고정한 추가 번호입니다. `tiles`의 `id`는 고유 번호, `height`는 논리 높이, `kind`는 지형 종류, `q`·`r`은 정수 축 격자 좌표, `group`은 구조 생성 당시 묶음 라벨입니다. 검증기는 `group`을 신뢰하지 않고 실제 다리에서 묶음을 재계산합니다.

`bridges`는 타일 목록 인덱스 두 개를 연결한 물리적 다리이며 `movementArcs`는 실제 통행 가능한 인덱스 방향 쌍입니다. 3→2만 제외됩니다. `validation`에는 수량·높이 경계 다리 수·묶음·묶음별 위/아래 연결·시작점 보호 거리·물리적 연결 검사 결과가 있습니다. `roundTripRequired=false`는 왕복을 검사 조건으로 요구하지 않는다는 뜻입니다.

`layout_bank.json`의 키는 높이 1·2·3의 추가 개수입니다. 값은 해당 수량을 만족하는 고정 구조입니다. `componentTargets`는 생성 시 목표 묶음 크기, `templateSeed`는 구조 탐색용 시드입니다. 실제 게임 시드와 별개입니다. `status`·`seconds`는 구조 탐색 상태와 경과 초입니다.

`invalid_*.json`은 잘못된 지도를 거부하는 회귀 검사용 데이터이며 실제 게임에 사용하지 않습니다. `*_results.json`은 테스트 수량·성공 여부·관측 확률을 기록합니다. PNG와 인접한 `sample_*.json`은 같은 시드의 원본 데이터입니다.
