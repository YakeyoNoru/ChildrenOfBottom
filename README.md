# ChildrenOfBottom

안드로이드 브라우저 중심, 최대 4인 실시간 멀티플레이 생존게임의 **초기 로비 프로젝트**입니다. 기존 TRPG 규칙은 포함하지 않습니다. 생존 플레이, 맵, 전투, 저장 기능 및 Unity 연결은 아직 구현하지 않았습니다. 시작 시 모든 클라이언트가 `started` 화면으로 전환됩니다.

## 실행

Node.js 22 이상과 npm이 필요합니다.

```sh
npm ci
npm start
```

PC: http://localhost:3000 에 접속합니다. 같은 Wi-Fi의 안드로이드에서는 `http://PC의사설IP:3000`으로 접속합니다. OS 방화벽에서 3000 포트를 허용해야 할 수 있습니다. 인터넷에서 다른 네트워크의 친구와 접속하려면 WebSocket 업그레이드를 지원하는 호스트에 이 서버를 배포하고 HTTPS/WSS를 적용하세요. 현재 프로젝트는 외부 배포되지 않았습니다.

`PORT`(기본 3000), `HOST`(기본 0.0.0.0), `ALLOWED_ORIGIN`(브라우저 허용 Origin, 예: https://game.example.com)을 환경변수로 설정할 수 있습니다. 기본값은 요청 Host와 같은 HTTP/HTTPS Origin만 허용합니다. Origin 없는 네이티브 클라이언트는 허용합니다.

```sh
npm test
npm run dev
```

## 규칙과 장애 처리

- 방 코드 6자리, 최대 4명(방장 포함). 참가자 이름은 공백 제거 후 1~20자입니다.
- 방장 외 참가자 모두 준비하면 시작 가능합니다. **혼자 시작도 허용**하여 개발과 개인 확인이 가능합니다.
- 방장은 준비 버튼 대신 시작 버튼을 사용합니다. 일반 참가자는 준비/준비해제를 전환합니다.
- 게임 시작 후 신규 참가와 준비 변경은 금지됩니다. 나가기는 가능합니다.
- 방장 퇴장/연결 종료 시 방을 삭제하고 남은 참가자에게 `방이 해제되었습니다.`를 표시한 뒤 메인으로 돌아갑니다. 일반 참가자 퇴장/연결 종료는 본인만 제거합니다.
- 서버가 15초 간격으로 ping을 전송합니다. 다음 검사까지 pong이 없으면 연결을 종료합니다(무응답 감지 약 15~30초). 명시적 연결 종료는 즉시 처리합니다. 모바일 백그라운드 전환으로 연결이 끊어져도 같은 규칙입니다.
- 브라우저는 연결 종료 시 메인으로 돌아가고 2초 간격으로 재접속합니다. 자동 방 복귀와 세션 복원은 없습니다. 참가자는 재접속 후 코드로 재참가할 수 있으며, 방장 방은 복구되지 않습니다.
- 요청 응답이 8초 동안 없으면 연결을 다시 수립합니다. 요청 중에는 중복 동작을 막습니다.
- 클립보드 복사는 HTTPS 또는 localhost에서 동작합니다. 일반 HTTP LAN 접속 등 권한이 없는 환경에서는 코드를 선택하고 수동 복사할 수 있도록 안내합니다.
- 방과 참가자는 메모리에만 존재하여 서버 재시작 시 사라집니다. 단일 서버 프로세스용입니다.

## 구조

- `server.js`: HTTP 정적 파일 제공, WebSocket 서버, 방 상태/권한/입력 검증
- `public/`: 한국어 반응형 UI. 로비 좌측 2/3 참가자 목록과 우측 조작부
- `test/lobby.test.js`: 실제 네트워크 연결을 통한 통합 테스트
- [PROTOCOL.md](PROTOCOL.md): 향후 Unity용 JSON WebSocket 계약

서버는 신뢰할 수 없는 클라이언트가 보낸 방장 ID/참가자 ID/방 상태를 사용하지 않습니다. 연결마다 발급한 ID와 서버 소유 방 상태로 권한을 확인합니다. 메시지 크기 4 KiB, 연결당 10초에 40요청, 방 1,000개 제한과 느린 수신자 종료가 적용됩니다. 계정 인증 및 IP별 접속 제한은 아직 없습니다. 방 코드는 초대용이며 영구 인증 수단이 아닙니다. 공개 운영 전에는 서비스 규모에 맞는 접속 제한과 운영 모니터링이 필요합니다.

## 확인 방법

브라우저 탭 4개에서 서로 다른 이름으로 접속하여 방을 생성하고 같은 코드로 참가합니다. 준비 전에는 시작이 비활성화되고 모든 참가자가 준비하면 활성화되는지 확인합니다. 다섯 번째 참가를 거절하는지, 일반 참가자 퇴장과 방장 퇴장/탭 종료 결과가 다른지 확인합니다. 안드로이드에서는 세로 화면, 코드 복사와 네트워크 끊김도 확인합니다.

자동 테스트는 4인 상태 동기화, 정원 초과, 권한 위조, 준비 토글과 타입 검사, 시작 후 참가 거절, 퇴장/연결 종료/heartbeat, 혼자 시작, 잘못된 JSON/버전/코드, 정적 파일 제한을 검증합니다.

사용한 WebSocket 구현과 heartbeat 처리 참고: [ws 공식 문서](https://github.com/websockets/ws/blob/master/README.md).
